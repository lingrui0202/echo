# 03 · 规则（胜负判定、数值边界）

> 状态：✅ 胜负、声呐、敌人、遥测全部实现

## 胜负

| 结果 | 触发 | 处理 | 遥测 `reason` |
|---|---|---|---|
| 通关 | 玩家进入出口 `Area2D` | `Player.win()` → 结算面板 | `"win"` |
| 失败 | 敌人靠近到 20 px | `Player.caught()` → 结算面板 | `"caught"` |
| 中途退出 | `R` 重开 / 关窗口 | 本局不写盘 | 无记录 |

> 已知行为：中途按 `R` 会直接开新局，上一局的数据**丢弃**。
> 如果以后要统计「弃局率」，需要补一个 `abandon` 记录（见 [99_decisions.md](99_decisions.md)）。

## 声呐规则

1. 只在 `_alive` 且 `_cd <= 0` 时可发；发一次 `_cd = 1.8`。
2. **同时只有一圈波**：再次发声会让上一圈立即消失（`emit_at` 重置 `_t` 并清空采样）。
3. 冷却按**物理帧**递减，与渲染帧率无关。
4. 发声顺序：余晖 → 波前 → 计数；三者必须同时发生，否则数据与画面会错位。
5. 发声没有资源消耗、没有失败惩罚（目前只有冷却和引来敌人这两个代价）。

## 波传播规则

| 规则 | 值 |
|---|---|
| 起始半径 | 6 px（避免 t=0 时退化） |
| 推进速度 | 420 px/s |
| 生命 | 1.6 s → 最大半径 672 px |
| 反射 | 最多 5 次，每次能量 ×0.72 |
| 终止 | 走完全程 / 用完反射次数 |
| 起点 | 玩家**发声瞬间**的位置，之后不再跟随 |

## 敌人规则

1. 玩家发声呐时，`level.emit_wave()` 同时把声源位置广播给所有敌人（`_alarm`）。
2. 敌人在 **700 px** 内就听见；**听觉穿墙**，不看视线，也不看中间有几道墙。
3. 听见后朝**声源所在格**追击 **4 s**，速度 110 px/s；追击期间不会更新目标（只认最后一声）。
4. 计时结束或到达目标格后停下，不再主动巡逻。
5. 敌人与玩家距离 ≤ **20 px** → `Player.caught()`；玩家已通关/已被抓时调用无效。
6. 敌人不挡路（玩家 mask 不含层 8），所以「穿过敌人」不会停下，只会被抓。
7. 每声最多惊动所有在半径内的敌人，`alerts` 记录被惊动的**次数总和**。

## 撞墙记忆规则

- 只有第 **1–2 跳**命中的点会留痕（更多跳是来回弹的余波，记下来整张图都会亮）。
- 写入 32 px 网格；同一格取较亮值；α = 0.26 × 能量。
- 每 4 帧 ×0.97，低于 0.02 清零；从最亮退完约 5–6 s（60 fps 复算；[README](../../README.md) 第 6 周按体感写的是 6–7 s）。
- 记忆属于**关卡**，不属于某一圈波：连续发声会叠加。

## 遥测规则

每条记录在 `end_session()` 时写入 `user://runs.json`：

| 字段 | 类型 | 含义 |
|---|---|---|
| `when` | string | 本地时间 |
| `reason` | string | `"win"` / 未来 `"caught"` |
| `duration_s` | float | 从 `start_session` 到结束 |
| `sonar_presses` | int | 本局发声次数 |
| `alerts` | int | 敌人听见声呐的次数总和（每只每次 +1） |
| `cells_visited` | int | 去重后的格子数 |
| `entries` | int | 进入格子的总次数 |
| `revisit_ratio` | float | `1 − cells_visited / entries`（`entries = 0` 时为 0） |
| `config` | object | 本局生效参数快照 |

`config` 必须包含：`sonar_cooldown`、`ambient_radius`、`ambient_energy`、`level`、`map_w`、`map_h`、`cell`、`wave_speed`、`wave_duration`、`max_bounces`、`segments`、`enemy_count`、`enemy_hear_radius`、`enemy_speed`、`enemy_chase_time`。

约束：

- **只追加**，最多 200 条，超出丢最旧。
- 旧记录可能没有 `entries` / `config`，读取方必须容忍缺字段。
- 写盘失败静默（没有磁盘权限时游戏照跑）。

## 数值边界（调参范围）

| 参数 | 下限 | 默认 | 上限 | 超出会怎样 |
|---|---|---|---|---|
| `SPEED` | 150 | 235 | 300 | 太快撞墙没反馈，太慢烦躁 |
| `SONAR_COOLDOWN` | 1.0 | 1.8 | 3.0 | < 1.0 可无限扫；> 3.0 变成等待游戏 |
| 波时长 `DURATION` | 0.8 | 1.6 | 2.5 | 太短看不清，太长屏幕常亮 |
| 波速 `RING_SPEED` | 300 | 420 | 600 | 太快像瞬亮，失去「推出去」的感觉 |
| `MAX_BOUNCES` | 0 | 5 | 8 | 太多会在墙角自激，画面碎 |
| `BOUNCE_LOSS` | 0.5 | 0.72 | 0.9 | 太低反射看不见，太高没有衰减感 |
| `SEGMENTS` | 96 | 220 | 320 | < 96 波前变多边形 |
| 光圈半径 | 24 | 56 | 96 | > 96 能看清相邻格，迷宫变简单 |
| 光圈能量 | 0.3 | 0.75 | 1.2 | 太亮盖过波前 |
| `CanvasModulate` | 0.005 | 0.015 | 0.05 | > 0.05 又变成「能看清路」 |
| `EDGE_DECAY` | 0.90 | 0.97 | 0.99 | 太低墙痕秒没，太高整屏残留 |
| 敌人听觉半径 | 400 | 700 | 1000 | < 400 基本听不见；> 1000 全图紧张 |
| 敌人速度 | 60 | 110 | 180 | > 180 追得上玩家，变成必死 |
| 敌人追击时长 | 2.0 | 4.0 | 8.0 | 太长会一路追到出口 |
| 接触半径 | 12 | 20 | 32 | 太小会贴脸不触发 |

> 一次只改一个；改完用 `runs.json` 的 `config` 分组对比，别凭感觉下结论。

## 边界情况

- **旧存档**：没有 `entries` 的记录，HUD 会显示「进入 0 次」但重复率非 0，这是历史数据兼容，不是 bug。
- **瞬移测试**：`test_win.gd` 会写一条 0.1 s 的通关记录，混进统计；分析数据时要按 `duration_s` 过滤。
- **窗口失焦**：Godot 默认继续跑，计时不会暂停。
- **自检不写盘**：`tools/selfcheck.tscn` 测「被抓」时把 `GameLog.persist` 设为 false，不会污染 `runs.json`。
- **双人同时按 R**：只有当前场景的 Player 响应，重载后旧节点释放。
