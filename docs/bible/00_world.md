# 00 · 世界 / 主题 / 美术调性

> 状态：✅ 已定（白盒阶段也要写，因为它决定所有取舍）

## 一句话世界观

一座被水淹了一半的地下声呐站。照明早就断了，你带着最后一台还能工作的脉冲声呐，
在回声里找出口。**这里没有光，只有回声。**

（当前版本没有叙事文本、没有 NPC；这段只用于统一美术与音效的判断标准。）

## 主题

**「看不见，所以听得见；听得见，所以被听见。」**

- 前半句是现在的机制：声呐把墙推出来。
- 后半句是第 7 周补上的机制：发声会暴露位置。
- 两者合起来才是这个游戏想说的事：**信息有代价**。

## 目标体验

玩家在 5 分钟内经历：迷失 → 试探 → 在脑子里画出地图 → 紧张（怕浪费/怕被听见）→ 冲刺出口。

写报告可直接用的一句话：

> 我希望玩家在 5 分钟内感到「紧张但逐渐掌控」——靠有限次数的声呐把黑暗变成一张记住的地图。

## 情绪曲线

| 阶段 | 时长 | 玩家状态 | 系统在做什么 |
|---|---|---|---|
| 迷失 | 0–20 s | 只看得见脚下一圈，乱撞 | 光圈 56 px、全黑 |
| 试探 | 20–60 s | 学会用波前读走廊 | 冷却 1.8 s 卡节奏 |
| 掌控 | 60–150 s | 开始记路、敢往深处走 | 撞墙记忆留痕 |
| 紧张 | 150 s+（第 7 周起） | 听见敌人、不敢乱发 | 敌人听觉 |
| 收束 | 最后 20 s | 直奔出口 | 出口绿光 |

## 美术调性

**极简几何 + 冷色 + 高对比的「光」**。白盒不是「临时凑合」，是这个游戏目前的最终形态。

| 元素 | 颜色 | 来源 |
|---|---|---|
| 背景/未照亮 | 近黑 `#040405` | clear color 0.02/0.02/0.04 |
| 墙 | 冷白蓝 `#D1E6FF` | `Polygon2D` 0.82/0.90/1.0 |
| 地面 | 深蓝灰 `#384056` | 0.22/0.25/0.34 |
| 网格 | 蓝紫 55% α | 0.36/0.46/0.78 |
| 波前 | 青 `#8CE0FF` | 0.55/0.88/1.0 |
| 撞墙记忆 | 淡蓝 α0.26 | 0.38/0.62/0.85 |
| 出口 | 荧光绿 `#4DFFA6` | 0.30/1.0/0.65 |
| 玩家 | 近白 | 0.88/0.96/1.0 |

规则：

- **只有「信息」可以发光**。装饰性光一律不加。
- 墙永远比地面亮，出口永远比墙亮，玩家永远最亮。
- 不做纹理、不做粒子（除非粒子承载信息，例如「敌人听见了」的提示）。
- 屏幕 90% 是黑的，这是设计，不是 bug。

## 参考与取舍

| 参考 | 取什么 | 不取什么 |
|---|---|---|
| 《Dark Echo》 | 声音即地图、脚步有信息 | 纯线条美术、无实体 |
| 《Lurking》 | 黑暗中的听觉恐惧 | 复杂叙事 |
| 《Scanner Sombre》 | 点云逐点显形 | 3D、彩色点云 |
| 《Echolocation》 | 脉冲扩散的节奏感 | 拟真物理 |

## 文本调性

- 中文，短句，第二人称，不用感叹号堆叠。
- HUD 只给状态和操作，不讲故事。
- 结算面板像实验记录：数字 + 一句「按 R 再试一次」。

## 白盒阶段的三条原则

1. **可读性 > 氛围**：看不清就是 bug，不是「沉浸感」。
2. **每个视觉元素都要承担信息**：网格是为了估距离，撞墙记忆是为了记路。
3. **先做能验证的**：任何「感觉更好」的改动，都要能用截图或 `runs.json` 证明。
