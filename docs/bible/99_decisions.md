# 99 · 决策日志（仅追加）

> 规则：
> 1. **只追加，不改旧条目**。要推翻一条，就新写一条并注明 `supersedes: D-xxx`。
> 2. 每条都要有「为什么」和「代价」，否则三个月后没人看得懂。
> 3. 代码与决策冲突时，以代码为准，并补一条说明。
> 4. 状态：`accepted` / `superseded` / `proposed` / `rejected`。

---

### D-001 · 地图用 ASCII 字符串，不用手摆节点
- 日期：2026-10-21 · 状态：accepted
- 决策：`level.gd` 里用 `MAP: Array[String]` 定义关卡，运行时生成墙、遮挡体、视觉、出口。
- 理由：改关卡只改字符串；碰撞体和遮挡体永远对得上；答辩能讲清「数据驱动」。
- 备选：编辑器手摆 200 个 `StaticBody2D`（易漏、难改）。
- 代价：地图不能做非格子形状；墙体合并逻辑要自己维护。

### D-002 · 零图片素材，贴图运行时生成
- 日期：2026-10-21 · 状态：accepted
- 决策：`light_factory.gd` 用 `GradientTexture2D` 生成径向/环状光斑，工程不放 png。
- 理由：没有美术也能做出统一的光感；提交体积小；参数化调整快。
- 代价：贴图精度受渐变限制，复杂图案做不了。

### D-003 · 波前画在 follow_viewport 的 CanvasLayer 上
- 日期：2026-10-27 · 状态：accepted
- 决策：`sonar_wave.gd` 建 `CanvasLayer(follow_viewport_enabled = true)` 再画。
- 理由：`CanvasModulate 0.015` 会把关卡里的 `CanvasItem` 乘到几乎全黑，画在关卡里等于没画。
- 代价：波与世界的坐标要自己对（目前 1:1，无缩放）。

### D-004 · 放弃二维波动方程，改几何波前
- 日期：2026-11-03 · 状态：accepted
- 决策：波前 = 220 条射线，撞墙按法线反射，末端连成轮廓。
- 理由：波动方程每帧正负翻转、在墙间来回弹，屏幕光暗一直在变，不可读。
- 代价：不是真物理，反射是「光线」而不是「声波」；但可读性优先。

### D-005 · 通道改成 2 格宽
- 日期：2026-11-03 · 状态：accepted
- 决策：`make_maze2.py` 逻辑格 2×2 字符 + 1 格墙，通道 128 px。
- 理由：1 格走廊里反射碎成小光斑，屏幕很乱。
- 代价：同样逻辑尺寸下地图更大、节点更多。

### D-006 · 地图放大到 61×34
- 日期：2026-11-03 · 状态：accepted
- 决策：采用 61×34、最短 144 步的迷宫。
- 理由：第 5 周试玩「15.8 秒通关，太小」。
- 代价：一局变长，需要相机限位与更好的导航线索（第 7 周补限位）。

### D-007 · 重复率按「进入格子」算
- 日期：2026-11-03 · 状态：accepted
- 决策：`revisit_ratio = 1 − 去重格数 / 进入次数`。
- 理由：旧版每帧采样，站着不动也能刷到 0.95，完全不代表走回头路。
- 代价：擦边经过同一格也算重复，数值偏保守。

### D-008 · 声呐冷却 1.8 s
- 日期：2026-11-03 · 状态：accepted（下一轮可能调整冷却）
- 决策：`SONAR_COOLDOWN = 1.8`。
- 理由：地图变大后给一点喘息，同时保留「不能一直扫」的约束。
- 代价：波 1.6 s / 冷却 1.8 s = 89% 占空比，约束偏弱（见 D-020）。

### D-009 · 全黑 0.015 + 环状光圈 56 px
- 日期：2026-10-27 · 状态：accepted
- 决策：`DARK = (0.015, 0.017, 0.028)`；光圈半径 56、能量 0.75、环状贴图。
- 理由：试玩反馈「还是看得清路，和普通迷宫没区别」；环状光圈让中心留暗，只给边界感。
- 代价：看不见相邻墙，只能撞或发声呐。

### D-010 · 声呐 = 几何波前 + 最多 5 次反射
- 日期：2026-11-03 · 状态：accepted
- 决策：420 px/s、1.6 s、5 跳、每跳 ×0.72。
- 理由：在墙角会拐弯，看起来像「回声绕过去」；参数少、可解释。
- 代价：CPU 开销固定（约 1.2 ms/帧，见 D-017）。

### D-011 · 撞墙留痕 6–7 秒
- 日期：2026-11-03 · 状态：accepted
- 决策：只记第 1–2 跳命中点，32 px 网格，α0.26，每 4 帧 ×0.97。
- 理由：把「刚才摸过哪面墙」外化成视觉记忆，减轻纯记忆负担。
- 代价：连续发声会让整条走廊发亮，削弱紧张感。

### D-012 · 验证以截图 + 脚本断言为准
- 日期：2026-10-21 · 状态：accepted
- 决策：每个机制改动都留 `_verify/*.png` 或脚本输出，README 记录复现命令。
- 理由：课程评分看「能不能运行、能不能解释、能不能发现偏差」。
- 代价：`_verify` 会膨胀，需要定期清理过期图。

### D-013 · 第 7 周修 5 个体验/正确性问题
- 日期：2026-11-07 · 状态：accepted
- 决策：出口光加遮挡；HUD 重开文案去重；波前折线加 64 px 断线；余晖半径对齐 672；相机限位。
- 理由：都是「能看见但说不出」的问题，改动小、收益明确。
- 代价：视觉变化小，需要截图对比才能看出。

### D-014 · 每条遥测记录带 config 快照
- 日期：2026-11-07 · 状态：accepted
- 决策：`player.gd` 记冷却/光圈，`level.gd` 记地图/波参数，`end_session` 写入。
- 理由：没有参数快照，改完 1.8 → 2.4 后两份数据无法归因，实验结论不成立。
- 代价：旧记录没有该字段，读取方必须容错。

### D-015 · 自检做成普通场景
- 日期：2026-11-07 · 状态：accepted
- 决策：`tools/selfcheck.tscn`，不依赖 `--script`，跑完写 `_verify/selfcheck.txt`。
- 理由：`--script` 在部分环境不可用；场景方式能在编辑器/MCP 里直接跑。
- 代价：多一套入口，需要和 smoke/test_win 保持同步。

### D-016 · 波前折线 64 px 断线
- 日期：2026-11-07 · 状态：accepted
- 决策：相邻采样点距离 > 64 px 就不连线。
- 理由：两条射线走了不同的路（一条被墙截住、一条拐进走廊）时，连直线会画出横穿墙壁的光柱。
- 代价：墙角处轮廓会有小缺口，用圆点补。

### D-017 · 暂不做声呐性能优化
- 日期：2026-11-07 · 状态：accepted
- 决策：保留 221 射线 + 全图衰减；不做 query 复用、不降到 144 段。
- 理由：实测 `_compute_ring` 1.19–1.25 ms/帧、`_decay_edges` 0.12 ms/帧，只占 60 fps 预算的 7%。
- 代价：加敌人后如果需要更多预算，得回头做（已有测量基线）。

### D-018 · 失败状态暂缺
- 日期：2026-11-03 · 状态：superseded by D-020（2026-11-07）
- 决策：当前只有通关，没有失败；`reason` 只可能是 `"win"`。
- 理由：先把「能通关」跑通，敌人设计留到第 2 阶段。
- 代价：声呐零风险，机制缺张力；报告里必须说明这是阶段性取舍。

### D-019 · 本 bible 作为单一事实源
- 日期：2026-11-07 · 状态：accepted
- 决策：数值、规则、实体、目录约定以 `docs/bible/` 为准；代码变更同步更新。
- 理由：README 是周记录（历史叙事），bible 是当前状态（可查询）；两者职责分开。
- 代价：多一份维护成本；好在每页都有状态标记，未实现的部分不会被误读。

### D-020 · 第 8 周：敌人 + 失败（accepted）
- 日期：2026-11-07 · 状态：accepted（supersedes: D-018）
- 决策：加 `Enemy`（听觉 700 px、速度 110 px/s、追击 4 s、BFS 寻路、20 px 接触），
  被抓写 `reason = "caught"`，HUD 复用结算面板、标题换成红色「被 听 见 了」。

- 备选：有限次数（8 次 + 回复）、波未消失不能再发 —— 都会同时改两个变量，先不做。

### D-021 · 敌人寻路用 MAP 上的格子 BFS
- 日期：2026-11-07 · 状态：accepted
- 决策：新增 `scripts/maze.gd`，`distances()` 与 `path()` 都只依赖 `Array[String]` 地图。
- 理由：MAP 已经是权威数据；运行时烘焙 `NavigationRegion2D` 多一层不一致，还要处理重建。
- 备选：`NavigationAgent2D`（更通用，但烘焙/同步麻烦）、贪心转向（墙角会卡）。
- 代价：每 0.4 s 一次 BFS（约 2000 格），暂时够用；地图再大要加缓存。

### D-022 · 出生点按 BFS 百分比分两段
- 日期：2026-11-07 · 状态：superseded by D-027
- 决策：`ENEMY_BANDS = [[0.55, 0.70], [0.80, 0.85]]`，每段从远到近挑一只，间隔 ≥14 格，排除出口。
- 理由：一只是中段压力，一只守出口；不写死坐标，改地图不用重对。
- 备选：手写坐标（直观但易错）、全图随机（不可复现）。
- 代价：出生点会随地图变化；难度曲线由百分比隐式决定，不直观。

### D-023 · 敌人自带 128 px 红色微光
- 日期：2026-11-07 · 状态：superseded by D-028
- 决策：敌人挂一盏 128 px、能量 0.18、`shadow_enabled` 的红光。
- 理由：敌人本体是全黑的 CanvasItem，只有被光打到才显形；完全不可见会变成「无故死亡」。
- 备选：完全不发光（更吓人但不可读）、全屏红边（过度提示）。
- 代价：多一盏带阴影的灯；暗处仍然只能看到 2 格左右。

### D-024 · 「被听见」的 HUD 提示
- 日期：2026-11-07 · 状态：accepted
- 决策：至少一只敌人听见时，左上角闪 1.5 s「！有东西听见了」；`GameLog.alert_count` 进遥测。
- 理由：声音没有方向、敌人又远，玩家需要知道「这一声暴露了自己」，否则机制不可学。
- 备选：只靠音效（音效还没做）、敌人尖叫（距离太远听不见）。
- 代价：每声都提示会略显吵；1.5 s 后消失，不影响沉浸。

### D-025 · 冷却暂不和敌人一起改
- 日期：2026-11-07 · 状态：accepted
- 决策：`SONAR_COOLDOWN` 保持 1.8 s，不随敌人一起改；冷却实验留到下一轮单独做。
- 理由：一次只动一个变量；否则「变难了」分不清是敌人还是冷却造成的。
- 备选：直接改 2.4（会失去归因）。
- 代价：当前占空比仍是 89%，可能偏宽松，需要下一轮数据。

### D-026 · `GameLog.persist` 测试开关
- 日期：2026-11-07 · 状态：accepted
- 决策：加一个只在自检里用的 `persist = false`，让「被抓」链路只在内存里记录，不写 `runs.json`。
- 理由：自检要验证 `caught` 全链路，但不能污染玩家的统计。
- 备选：让自检写一条假记录（会进通关率/均值）、跳过全链路测试（覆盖不足）。
- 代价：生产代码多一个测试钩子；默认 true，正常游戏不受影响。

### D-027 · 敌人改到「起点→出口」路线旁（supersedes D-022）
- 日期：2026-11-07 · 状态：accepted
- 决策：`ENEMY_ROUTE_FRACS = [0.30, 0.65]`；在最短路上取锚点，四邻里找一个
  **不在路线上**的开放格，两只间隔 ≥10 格。
- 理由：试玩反馈「玩的时候没看见敌人」。旧方案按 BFS 距离分段，两只都在 100/122 步，
  离最短路线最近也有 3 格，前半局完全遇不到；新方案保证沿正常路线会经过敌人 1 格以内。
- 备选：保留 BFS 分段、加巡逻（更复杂）；把敌人直接放路线上（会堵死唯一通道）。
- 代价：出生点依赖路线形状；找不到旁格时会退回锚点（自检 `_route_min >= 1` 会报）。
- 备注：这次改动由自检新增的「路径上离敌人最近多少格」指标发现旧值 0 → 新值 1。

### D-028 · 敌人红光提到 192 px / 0.32 并加呼吸（supersedes D-023）
- 日期：2026-11-07 · 状态：accepted
- 决策：自光半径 128 → 192 px，能量 0.18 → 0.32；2 Hz 轻微呼吸，追击时亮 1.6 倍。
- 理由：128 px 只有 2 格，玩家按 235 px/s 走时只有约 0.5 s 反应时间，实测很难注意到。
- 备选：完全靠音效（还没做）、把敌人画在不受黑暗影响的层（会隔墙可见）。
- 代价：敌人更容易被提前发现，「吓一跳」的成分变少。

### D-029 · 自检断言「敌人不在最短路上」
- 日期：2026-11-07 · 状态：accepted
- 决策：计算起点→出口最短路，断言路径到敌人的最近格距离 ≥ 1，并把该距离写进报告。
- 理由：第一次改路线生成时两只敌人正好落在路线上（距离 0），玩家会直接撞死；
  这个数只有算出来才看得见。
- 备选：靠试玩发现（太晚）。
- 代价：自检多算一次 BFS（<1 ms）。
