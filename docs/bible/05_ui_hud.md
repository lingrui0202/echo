# 05 · UI / HUD

> 状态：✅ 四个部件（状态行 / 被听见提示 / 数据面板 / 结算）；⬜ 冷却指示 / 暂停未做

## 原则

- HUD 全部在 `CanvasLayer` 上，不受 `CanvasModulate` 影响（世界可以全黑，文字必须能读）。
- 只显示**下一步要用**的信息：时间、次数、操作；不显示坐标、不显示小地图。
- 中文短句；数字用等宽感排版（`%5.1f` 占位，避免数字跳动）。

## 布局

| 部件 | 节点 | 位置 | 字号 | 颜色 |
|---|---|---|---|---|
| 状态行 | `Label` `_hint` | 左上 (16, 10) | 18 | 0.75 / 0.90 / 1.0 |
| 被听见提示 | `Label` `_alert` | 左上 (16, 40) | 18 | 1.0 / 0.55 / 0.45 |
| 数据面板 | `PanelContainer` `_panel` | 左上 (16, 72) | 16 | 默认主题 |
| 结算面板 | `PanelContainer` `_result` | 屏幕中央（anchor center） | 20 | 通关蓝 / 被抓红 |

- 结算面板 `horizontal_alignment = center`，宽高随内容撑开。
- 面板样式用 Godot 默认主题（**已知的打磨点**：之后可换成半透明深色 `StyleBoxFlat`）。

## 状态机

| 状态 | 条件 | 状态行 | 结算面板 |
|---|---|---|---|
| 游玩中 | `last_reason` 为空 | 正常显示 | 隐藏 |
| 被听见提示 | `GameLog.alert_age() < 1.5` | 下方闪「！有东西听见了」 | 隐藏 |
| 通关 | `last_reason == "win"` | 末尾加「通关！」 | 显示，蓝标题 |
| 被抓 | `last_reason == "caught"` | 末尾加「被听见了」 | 显示，红标题 |
| 数据面板开 | `Tab` 切换 | 不变 | — |

## 文案（当前实际字符串）

状态行：

```text
%5.1f s    声呐 %d 次    [空格] 发声呐   [Tab] 数据   [R] 重开
```

通关时在末尾追加：

```text
    通关！
```

> 第 7 周修过一个 bug：旧版 `tail` 里又拼了一次「[R] 重开」，通关后同一行出现两次。
> 现在重开提示只在基础行出现一次。

被抓时用同一个模板，标题换成 `被 听 见 了`，文字颜色换成 1.0 / 0.62 / 0.55。

## 被听见提示

```text
！有东西听见了
```

- 位置 (16, 40)，红字，显示 1.5 s；`GameLog.alert_age() < 1.5` 时可见。
- 触发：`GameLog.note_alert(n)`，由 `level._alarm()` 在至少一只敌人听见时调用。
- 结算面板弹出后不再显示（`ended` 时强制隐藏）。
- 没有这个提示，玩家不会知道这一声已经暴露了自己 —— 这是敌人机制的公平性底线。

结算面板：

```text
通  关

用时 %.1f s     声呐 %d 次
走过 %d 格（进入 %d 次）
重复率 %.0f %

按 R 再试一次
```

数据面板（`Tab`）：

```text
最近 %d 局统计
平均用时        %.1f s
平均声呐次数    %.1f 次
平均走过格子    %.0f
平均重复率      %.0f %
通关率          %d / %d
最好成绩        %.1f s

本局：%s   %.1f s   声呐 %d 次
本局参数：冷却 %.1f s
（数据文件：user://runs.json）
```

## 数据来源

| 显示 | 来源 |
|---|---|
| 用时 | `GameLog.elapsed()`（结束后冻结） |
| 声呐次数 | `GameLog.sonar_count` |
| 被听见次数 | `GameLog.alert_count`（本局，不显示在面板，进 `runs.json`） |
| 走过格数 / 进入次数 | 最近一条记录 `cells_visited` / `entries` |
| 重复率 | `1 − cells_visited / entries` |
| 最好成绩 | 全部记录里 `reason == "win"` 的最小 `duration_s` |
| 本局参数 | `GameLog.config["sonar_cooldown"]` |

## 视觉规格

- 字体：Godot 默认字体（无外挂字体）。
- 安全边距：16 px；面板内边距沿用默认主题。
- 对比：正文亮度 ≥ 0.75；不使用纯白（避免在近黑背景上刺眼）。
- 结算面板不遮全屏：只在中央，四周仍能看到环境。

## 待做（按优先级）

1. **冷却指示**：玩家脚下 12 px 细弧，或状态行加一个「▮▮▯」进度；不然玩家不知道还要等多久。
2. **提示的方向感**：现在只说「有东西听见了」，不说哪边；可以按相对位置在提示后面加 ← / →。
3. **结算面板样式**：`StyleBoxFlat` 深色半透明 + 1 px 描边，比默认灰更好读。
4. **暂停**：`Esc` 暂停并显示当前参数（方便做实验对照）。
5. **首次提示**：开局 3 s 内显示「空格 = 发声呐」，之后淡出。

## 验收

- 全黑场景下 1 m 外能读清状态行（对比度检查）。
- 通关 / 失败面板切换不闪、不重叠。
- 数字格式固定宽度，计时跳动时整行不抖。
