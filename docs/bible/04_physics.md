# 04 · 物理 / 数值参数

> 状态：✅ 现有系统，敌人参数已实现

## 坐标系与单位

- 2D，原点在地图**左上角**，x 向右、y 向下。
- 1 世界单位 = 1 px；1 格 = **64 px**。
- 地图 61×34 格 = **3904×2176 px**；视口 1152×648 px（18×10.1 格）。
- 物理帧 60 Hz；所有计时用 `Time.get_ticks_msec()`，不用帧数。

## 碰撞层

| 层 | 用途 | 谁在 | 谁掩码 |
|---|---|---|---|
| 1 | 墙 | `Walls` 的 `StaticBody2D` | 玩家、波射线、敌人 |
| 2 | 玩家 | `Player` | 出口 `Area2D` |
| 4 | 出口 | `Goal` 的 `Area2D` | 玩家层 2 |
| 8 | 敌人 | `Enemy` | 墙（不掩码玩家） |

> 新增实体**不许**复用 1 / 2 / 4；从 8 开始往后排。

## 移动

| 项 | 值 |
|---|---|
| 速度 | 235 px/s（恒定，无加速） |
| 输入 | `Input.get_vector` 归一化，斜向不加速 |
| 碰撞 | `move_and_slide()`，贴墙滑行 |
| 半径 | 9 px 圆 |
| 边界 | 由边界墙挡住，不会出图 |

> 本工程**没有 `RigidBody2D`**，所以弹性、冲量、摩擦都是 0；碰撞只是 `move_and_slide` 的位置修正，
> 不做反弹。如果以后要加「推箱子」之类的物体，再单独定义物理材质。

## 光照模型

| 光 | 类型 | 半径 | 能量 | 阴影 |
|---|---|---|---|---|
| 常亮光圈 | `PointLight2D` + 环状贴图 | 56 px | 0.75 | 开 |
| 声呐余晖 | `PointLight2D` + 径向贴图 | 672 px | 0.12 → 0 | 开 |
| 出口灯塔 | `PointLight2D` + 径向贴图 | 45 px | 0.55 | 开（第 7 周修） |
| 全局黑暗 | `CanvasModulate` | — | 0.015 / 0.017 / 0.028 | — |

规则：

- 贴图全部运行时生成（[scripts/light_factory.gd](../../scripts/light_factory.gd)），工程零图片。
- `PointLight2D.shadow_enabled` **默认 false**，不显式打开就会穿墙。
- 遮挡体多边形必须顺时针；一个 `StaticBody2D` 上挂一个 `LightOccluder2D`。
- `CanvasModulate` 会把普通 `CanvasItem` 乘到接近全黑，所以波前画在 `follow_viewport` 的 CanvasLayer 上。

## 声呐几何

| 量 | 公式 / 值 |
|---|---|
| 波前半径 | `r = min(672, 420 × t)`，最小 6 px |
| 单帧推进 | 420 / 60 = 7 px |
| 采样点 | 221 个（`SEGMENTS + 1`），圆周均布 |
| 相邻点弧长 | `2πr / 220`，r=672 时约 19 px |
| 连线上限 | 64 px（超过就断线，防止跨墙光柱） |
| 反射 | `d = d.bounce(normal)`，每次能量 ×0.72 |
| 射线查询 | `PhysicsRayQueryParameters2D`，mask = 1 |
| 采样间隔 | 波前每帧重算；墙记忆每 4 帧衰减一次 |

## 撞墙记忆

| 项 | 值 |
|---|---|
| 网格 | 32 px（地图 122×68） |
| 写入 | 第 1–2 跳命中点，α = 0.26 × 能量 |
| 衰减 | 每 4 帧 ×0.97（约 15 次/s） |
| 清除 | α < 0.02 |
| 画面 | `Sprite2D`，`BLEND_MODE_ADD`，线性过滤 |

## 性能预算

60 fps = 16.7 ms/帧。实测（RTX 3050 / Vulkan Forward+，第 7–8 周多次运行）：

| 项 | 实测 | 占预算 |
|---|---|---|
| 波前 `_compute_ring` | 1.17–1.33 ms/帧 | ~7–8% |
| 墙记忆 `_decay_edges` | 0.43–0.49 ms 每 4 帧 → 约 0.12 ms/帧 | < 1% |
| 余晖 / 光圈 / 出口光 / 敌人红光 | 未单独测 | 未知 |

优化顺序（**有测量再做**）：复用 query 对象 → 降到 144 段 → 只衰减活跃格。
现在不做，理由见 [99_decisions.md](99_decisions.md) D-017。

## 敌人物理

| 项 | 值 |
|---|---|
| 碰撞体 | 圆半径 12 px，`layer 8 / mask 1` |
| 速度 | 110 px/s（玩家 235） |
| 转向 | 每 0.4 s 用 BFS 重算到声源格的路径，沿格子中心走 |
| 听觉 | 700 px，穿墙，只判距离 |
| 接触 | 距离 ≤ 20 px（不靠碰撞层） |
| 自光 | 192 px 红色微光，能量 0.32，`shadow_enabled`，约 3 s 一次呼吸 |
| 每帧开销 | 追击时每 0.4 s 一次 BFS（约 2000 格），其余帧只走路径 |

> 敌人不挡玩家：玩家 `mask` 只有 1，层 8 不在其中，所以两者会重叠，靠距离判定结束游戏。
